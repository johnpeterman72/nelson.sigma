# Nelson♦Σ

Nelson♦Σ is a zero-dependency Claude Code skill for coordinating agent work using Royal Navy terminology: an eight-step operational framework (Sailing Orders, The Estimate, Battle Plan, Form the Squadron, Get Permission to Sail, Quarterdeck Rhythm, Action Stations, Stand Down) written in the symbolic notation defined in `skills/nelson/references/sigma-legend.md` and run entirely on native Claude Code tools.
