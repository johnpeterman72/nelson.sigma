# Nelson♦Σ

Nelson♦Σ is a token-compressed edition of Nelson, a Claude Code skill for coordinating agent work using Royal Navy terminology. It provides an eight-step operational framework: Sailing Orders, The Estimate, Battle Plan, Form the Squadron, Get Permission to Sail, Quarterdeck Rhythm, Action Stations, and Stand Down — written in symbolic notation defined in `skills/nelson/references/sigma-legend.md`.
