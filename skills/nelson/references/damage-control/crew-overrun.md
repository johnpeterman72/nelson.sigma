# Δ₆ Crew Overrun: Ship Budget Recovery

Crew burning tokens ∨ time out of proportion to task weight.

1. CPT pauses ∀ crew.
2. Reviews each against sub-task + budget.
3. Source: scope creep ∨ blocked ∨ role mismatch.
4. Creep → descope to the original sub-task · blocked → resolve ∨ reassign · mismatch → correct role ∨ CPT does it.
5. Resume with a revised budget.
6. Cannot recover within budget → ADM with summary + recommendation: extend ∨ descope ∨ split to a second ship.

Automated `cost_per_task_overrun` alarm: `damage-control/circuit-breakers.md`.
